## Rules

1. Never hand-edit anything under `out/`. It is generated.
2. Never invent data. Every project claim must trace to `src/data/projects.ts` (curated
   from GitHub API facts as of 2026-11-25, lineage from the
   `hamids-ai-automations/github-profile-master-record` master record) or to a curated
   override that restates a verified fact. No invented clients, testimonials, or metrics.
3. Never add an email, phone-call, Telegram, or contact-form CTA. WhatsApp only — enforced
   by CSP `form-action 'none'` and `scripts/validate.mjs`.
4. Never commit secrets. Deployment credentials live in GitHub Actions secrets
   (`WIF_PROVIDER` + `WIF_SERVICE_ACCOUNT`, preferred, or `FIREBASE_SERVICE_ACCOUNT`).
5. Every page needs a unique title, unique meta description, canonical URL, exactly one
   H1, and a WhatsApp CTA — the validator enforces all of it.
6. Run `bun run ci` before every push. A failing build must never reach `main`.
7. `public/og.png` and `public/apple-touch-icon.png` are build artifacts generated by
   `scripts/generate-og.mjs` — **never commit them**. They are gitignored on purpose.

## Workflow

```bash
bun install          # dependencies from bun.lock
bun run dev          # local dev server (http://localhost:3000)
bun run lint         # ESLint
bun run typecheck    # TypeScript
bun run og           # regenerate OG image + touch icon (build artifacts)
bun run build:export # static export → out/
bun run validate     # post-build gate: SEO, links, machine surfaces
bun run ci           # all of the above, in order — run before every push
bun run deploy       # ci + firebase deploy --only hosting:marvis
```
